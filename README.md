# 📊 Campus Placement Data Analysis (EDA)

An end-to-end Exploratory Data Analysis (EDA) project using Python to uncover the underlying patterns behind successful campus placements and corporate salary distributions.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 🔍 Key Business Insights Discovered
1. **The Work Experience Advantage:** KDE analysis reveals that students with prior corporate exposure (`workex`) enjoy a massive competitive edge, showing significantly higher placement rates and top-tier salaries.
2. **Academic Streams vs. Pay Scale:** While Commerce & Management students accounted for the highest volume of placements, Science & Technology graduates commanded the highest average packages (~₹3.14L).
3. **Specialization Demand:** Choosing **Marketing & Finance** yielded higher recruitment consistency compared to **Marketing & HR**.

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Ensure you have Python and Jupyter Notebook installed.
3. Install dependencies: `pip install pandas numpy matplotlib seaborn`
4. Run `pythonfile.ipynb`.
